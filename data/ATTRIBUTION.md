# Data attribution

`kanji.json` is generated by `tools/build_kanji_data.py` from:

- **KANJIDIC2**, © Electronic Dictionary Research and Development Group (EDRDG),
  used under the [EDRDG licence](https://www.edrdg.org/edrdg/licence.html)
  (Creative Commons Attribution-ShareAlike 4.0). Provides meanings, readings,
  school grade, stroke count, frequency and classical radical.
- **KanjiVG**, © Ulrich Apel, [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/).
  Provides the component breakdown, radical and phonetic (`kvg:phon`) annotations.

The derived `kanji.json` is distributed under CC BY-SA 4.0.

Radical names come from Unicode Kangxi Radical character names.

No WaniKani content lives in this repository. The app fetches it at runtime with the
user's own API token and stores it only in that device's IndexedDB.
